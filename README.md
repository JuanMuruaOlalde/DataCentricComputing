# Data Centric Computing

El lema de este proyecto es: "Por donde van datos no van ejecutables, y viceversa"

No podremos trabajar tranquilos con un ordenador hasta que tengamos seguridad en lo que hace. Y eso es imposible de conseguir mientras su código ejecutable pueda actualizarse en cualquier momento. O, peor aún, mientras nos pueda llegar código ejecutable mezclado con los datos que intercambiamos.

Los datos pueden y han de circular con fluidez de un sistema a otro. 

Pero el código ejecutable que maneja esos datos ha de estar estrictamente controlado (y aislado) en cada sistema. Siendo responsabilidad de las personas que manejan cada sistema.
